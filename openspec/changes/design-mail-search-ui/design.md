# Почта · дизайн-спецификация

Документ фиксирует интерфейс почты для хакатона VK Tech на ревизии `9784bce`. Его можно использовать для сборки макетов в Figma и сверки вёрстки. Рабочий экран открывается на «Входящих». Поиск доступен сверху, ящик и дата отсчёта — в панели навигации. Главный сценарий — найти известное письмо по описанию и открыть его в контексте выдачи.

[Функциональные требования](specs/mail-search-ui/spec.md) · [Реализация](../../../mail_search/index.html) · [Сценарии проверки](tasks.md)

## 1. Структура и адаптация

### Ноутбук

```text
┌─ Почта ──────────────┬─ Поиск по письмам ─────────── [Найти] ──────┐
│ Ящик 02 · 4602      │                                            │
│ Дата отсчёта        │ ┌─ Результаты поиска ──┬─ Открытое письмо ┐ │
│ Входящие            │ │ Счётчик · День       │ Тема              │ │
│                     │ │ Тема · Дата           │ Дата              │ │
│                     │ │ Фрагмент             │ Полный текст      │ │
│                     │ │ Следующие письма     │                   │ │
│                     │ └──────────────────────┴───────────────────┘ │
└─────────────────────┴────────────────────────────────────────────┘
```

- Опорный фрейм **1280 × 800 px**. Сетка состоит из фиксированных 240 px слева и резиновой области справа. Верхний ряд занимает около 74 px. Колонки слева и справа начинаются на одной горизонтали.
- Справа белая верхняя панель. Поле и кнопка стоят в одном ряду, общий блок занимает до 800 px. Поле растягивается, кнопка подстраивается под текст.
- Рабочая область справа отделена от панели и краёв. Вертикальные отступы 16 px, горизонтальные от 16 до 32 px по ширине окна. При 1280 px горизонтальный отступ около 29 px.
- Список и чтение занимают примерно 40% и 60% внутренней ширины. Минимальная ширина списка 240 px. Между панелями граница 1 px. Список и письмо прокручиваются независимо. Заголовок и статус выдачи остаются над прокручиваемыми строками.
- При открытии письма выбранная строка видна слева, её фон и синяя полоса показывают, какое письмо открыто. Письмо начинается с темы и даты, полный текст идёт под разделителем.

### Телефон и узкое окно

- При ширине до **55 rem включительно**, около **880 px** при базовом размере шрифта 16 px, интерфейс переходит на одну колонку. Опорный фрейм **360 × 700 px**.
- Порядок экрана списка сверху вниз. Бренд, поиск, ящик и дата отсчёта, кнопка «Входящие», затем список. Ящик и дата делят доступную ширину пополам с промежутком около 10 px. Внешние боковые отступы 16 px.
- При выборе строки показываются бренд, кнопка «К результатам» и письмо. Поиск, параметры и список скрыты на время чтения. Чтение начинается сверху.
- Возврат восстанавливает список с тем же запросом и датой, выбранную строку, позицию прокрутки и фокус. Входящие и выдача используют один и тот же экран списка.

## 4. Поведение и состояния

| Когда | Что показывает интерфейс | Действие |
| --- | --- | --- |
| Первый вход | «Загружаем почтовые ящики…», поля недоступны. Затем «Входящие» с первым ящиком и его датой по умолчанию. | После загрузки можно искать, выбирать ящик или читать письма. |
| Ящиков нет | «Нет доступных почтовых ящиков.» | Поля остаются недоступными. |
| Не загрузились ящики | «Не удалось загрузить почтовые ящики.» | «Повторить» загружает ящики снова. |
| Выбран другой ящик | Обновлённые «Входящие», дата по умолчанию нового ящика. | Поисковая строка очищается, открытое письмо сбрасывается. |
| Нажаты «Входящие» | Последние письма текущего ящика, выбранная папка подсвечена. | Запрос очищается, выбранная дата сохраняется. |
| Отправлен запрос или изменена дата | «Ищем письма…». После ответа — результат для актуального ящика, даты и запроса. | «Найти» и Enter запускают поиск. Отправка пустой строки открывает входящие. |
| Найдены письма | «Показано: N» во входящих или «Писем в выдаче: N» в поиске. | N — число строк в ответе. Порядок строк повторяет API. |
| Сервер распознал день | Подпись «За 1 октября 2028 г.» рядом со статусом. | День берётся из ответа сервера и показывается даже при пустой выдаче. |
| Включился резервный режим | «Поиск по словам» рядом со статусом. | Строки доступны для чтения. |
| Пустые входящие | «На эту дату в ящике нет писем.» | Можно изменить дату или ящик. |
| Нет результатов | «Письма не найдены. Попробуйте другой запрос.» | Фокус и редактирование доступны в строке поиска. |
| Поиск вернул 503 | «Поиск временно недоступен.» | «Повторить» заново запускает поиск с текущими значениями полей. |
| Сетевой сбой поиска | «Не удалось загрузить письма.» | Доступен повтор. Введённый запрос остаётся в поле. |
| Письмо ещё не выбрано | Конверт и «Выберите письмо из списка.» | Выбрать строку мышью или с клавиатуры. |
| Открытие письма | «Открываем письмо…», строка выделена. | На телефоне фокус переносится в область чтения. |
| Письмо открыто | Тема, дата и полный текст. Для пропусков «Без темы» и «Дата неизвестна». | На телефоне «К результатам» возвращает на ту же строку. |
| Письмо вернуло 404 | «Письмо недоступно. Выберите другое в списке.» | На ноутбуке список рядом. На телефоне есть кнопка возврата. |
| Другой сбой чтения | «Не удалось открыть письмо.» | «Открыть снова» повторяет запрос для того же письма. |

После нового поиска, смены ящика или выбора другого письма запоздалые ответы от прежнего действия не меняют экран. В режиме чтения длинные слова и ссылки переносятся на новую строку. Тело письма выводится как текст с сохранением переносов.

## 5. Привязка к API

| Источник | Поля и отображение |
| --- | --- |
| `GET /api/mailboxes` | Ключ объекта — ID ящика, значение — дата по умолчанию либо `null`. Подпись в списке строится из порядкового номера в ответе и последних четырёх символов ID, например «Ящик 02 · 4602». В запрос передаётся полное значение. При пустой дате интерфейс подставляет текущий локальный день. |
| `GET /api/search` | Параметры `mailbox`, `as_of`, `q`. Строка берётся из `subject`, `day`, `preview`. `doc_id` используется для открывания. По умолчанию API возвращает до 20 строк. |
| Заголовки поиска | `X-Target-Day` управляет подписью дня. При его отсутствии подпись скрыта. `X-Search-Mode: bm25-fallback` включает «Поиск по словам». |
| `GET /api/message` | Параметры `mailbox` и `as_of` берутся из запроса, который породил список. `doc_id` — из строки. Интерфейс выводит `subject`, `day`, `body`. |

## 6. Сборка файла Figma и кликабельный сценарий

1. Создать четыре страницы. `References` для скриншотов, `Foundations` для переменных и стилей, `Components` для наборов вариантов, `Flows` для экранов.
2. В `Flows` собрать фреймы `Desktop/Inbox`, `Desktop/Search`, `Desktop/Search with message`, `Mobile/Inbox`, `Mobile/Search`, `Mobile/Reader`. Варианты загрузки, пустой выдачи, ошибки и резервного режима оформить рядом как отдельные фреймы с теми же экземплярами компонентов.
3. Собрать широкий экран из двух вертикальных контейнеров. Слева фиксированные 240 px, справа `Fill`. В рабочей области при 1280 px взять около 392 px для списка и 588 px для чтения, после чего проверить пропорцию 40/60 на других ширинах. Включить обрезку содержимого во фрейме и вертикальную прокрутку внутри списка и письма. На телефоне сделать экран списка одним вертикальным Auto Layout с прокруткой всего фрейма.
4. Связать переходы `Inbox → Search → Search with message` и `Mobile/Inbox → Mobile/Search → Mobile/Reader → Mobile/Search`. В мобильном возврате использовать экземпляр списка с той же выбранной строкой и позицией. Для выбора ящика связать вариант «Открыто» с входящими другого ящика. Для кнопки повтора связать ошибку с загрузкой и затем с успешной выдачей.
5. Подставить данные для демо. Выбрать «Ящик 02 · 4602» и дату отсчёта 2 октября 2028 года, ввести «Электронные чеки за вчера». Над выдачей должно быть «За 1 октября 2028 г.». Открываем письмо «Ваш чек + (1) подарок. „Служба Берег“ за 01.10.2028». Этот пример совпадает с экраном на реальном API.

## 7. Приёмка макетов

- На каждом опорном размере из раздела «Референсы экранов» можно найти ящик, запустить поиск, понять дату результата и прочитать письмо. При ширине 360 px нет горизонтальной прокрутки.
- Открытое меню показывает понятные подписи ящиков. У поля в закрытом виде остаётся место под шеврон. На телефоне и ноутбуке показаны одни и те же подписи.
- Тема переносится при узкой ширине, фрагмент занимает максимум две строки, полное тело доступно прокруткой. Есть примеры письма без темы и без даты.
- Состояния «пустой ящик», «ничего не найдено», «письмо недоступно» и «сбой поиска» визуально различимы по тексту и доступному действию.
- Видимы клавиатурный фокус и выбранная строка. Enter отправляет запрос и открывает строку, а на телефоне возврат восстанавливает позицию и фокус. Проверку этих взаимодействий проводят в браузере.
