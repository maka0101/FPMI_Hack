| 2. Интеграция и состояния | Фронтенд + бэкенд | На существующем API пройти поиск и открытие письма. Воспроизвести пустой ответ, 404, 503, резервный режим и запоздалый ответ. |

| 4. Демо | Фронтенд + команда | На машине для защиты пользователь самостоятельно находит и открывает нужное письмо. Зафиксировать запрос, ящик и дату для воспроизведения. |

## Проверка реализации

- Схема согласована. В Chrome при 1280 × 800 проверены поиск клавишей Enter, дата из ответа API, порядок строк и открытие выбранного `doc_id`.
- При 360 × 700 проверены отдельный экран письма и возврат с сохранением даты, выделения, фокуса и позиции прокрутки.
- В браузере воспроизведены сетевой сбой, ответы 404 и 503, повтор запроса, пустой ящик, резервный режим и запоздалый ответ.
- Сценарий для демо на корпусе. Ящик `box-2d28af4e4602`, дата отсчёта 2 октября 2028 года, запрос «Электронные чеки за вчера». В выдаче отображается 1 октября 2028 года. Откройте письмо «Ваш чек + (1) подарок. „Служба Берег“ за 01.10.2028».
