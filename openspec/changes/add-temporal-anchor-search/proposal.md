# Proposal

## Why

Человек может помнить знакомое письмо и его связь с нужным событием, хотя забыл точную дату и отправителя искомого письма. Выбор письма-ориентира помогает уточнить обычный запрос, когда в выдаче много похожих писем.

## What Changes

- Действие «Помню, что было рядом» открывает форму поиска ориентира. Человек выбирает одно из трёх писем по теме, отправителю и дате, затем указывает направление.
- Поиск ограничивает оба списка гибридного ранжирования окном в три календарных дня вокруг ориентира с учётом направления и даты отсчёта. Выдача показывает применённое условие и расстояние до ориентира в днях.
- При пустой выдаче можно расширить окно до семи дней. С пустым основным запросом можно просматривать письма от ближайших к более далёким.
- MVP использует отдельные поля для основного запроса и ориентира. Разбор связи между ними из одной фразы остаётся следующим этапом.

## Impact

- Backend и ML используют существующие индексы, календарные диапазоны и гибридное ранжирование. Новые операции поиска доступны из веб-интерфейса рядом с обычной строкой поиска.
- Карточки используют существующую панель чтения. На корпусе хакатона доступны даты получения с точностью до дня. Отправитель берётся из размеченной шапки письма, когда она есть.
- До разработки интерфейса сравним позиции письма в обычном топ-10 и в топ-10 с окном вокруг узнаваемого ориентира в том же ящике.
