# Умный поиск в Почте

Прототип для кейса VK Tech. В репозитории лежат [данные участников](mipt_mail_search_participants/README.md), поисковый движок и веб-интерфейс для поиска и просмотра писем.

Для запуска нужен Python 3.9+ со встроенным SQLite FTS5. Устанавливать пакеты или загружать веса не требуется.

```sh
python3 -m mail_search serve
```

Откройте [локальный интерфейс](http://127.0.0.1:8000). Выберите почтовый ящик, задайте дату отсчёта и введите запрос. Пустой запрос показывает последние доступные письма. Для запроса «электронные чеки вчера» день получения вычисляется относительно выбранной даты.

Движок строит индекс в памяти при запуске и ранжирует результаты по BM25 с повышенным весом темы. Для русских слов он учитывает точную форму и совпадения по префиксу. Поиск ограничен выбранным ящиком и исключает письма, полученные после даты отсчёта. Поддерживаются «сегодня», «вчера», «позавчера» и конкретные даты. При поиске за конкретный день письма без даты не попадают в выдачу. Это лексический baseline, который может пропускать перефразировки без совпадений слов.

## Публичный бенчмарк

```sh
python3 -m mail_search benchmark --limit 10 --output rankings.jsonl
```

Команда запускает тот же поиск, что и веб-интерфейс, с ящиком и датой из каждого запроса. Она печатает Recall@K и nDCG@K по размеченным запросам, MRR@K по запросам с одним релевантным письмом и p99 времени вызова поиска без индексации. Флаг `--output` сохраняет по одной строке JSON на запрос с полями `query_id` и `doc_ids` в порядке выдачи.
