# Поиск пяти писем на 99 исходных запросах

Лучший nDCG@5 на проверенной сетке — 0,98378. Конфигурации с этим результатом: Harrier 270M 69 / 31.

Проверена 51 конфигурация двухветочного гибрида BM25 и эмбеддера в ветке ML на той же разметке, что в [эксперименте с top-10](weights-fine.md). Каждый HTTP-запрос к локальному /api/search содержал limit=5. После фильтров по ящику и дате каждая ветка могла дать до 50 кандидатов для RRF. В таблицах указаны веса BM25 и эмбеддера в процентах.

Recall@5 и nDCG@5 усреднены по 99 запросам. MRR@5 считается по 42 запросам с одним целевым письмом. Даже идеальный поиск на этом наборе достигает Recall@5 только 0,86298, поскольку у части запросов больше пяти релевантных писем.

Модели прогонялись последовательно на Apple M4 Pro. E5 работал на CPU в ONNX INT8, Granite и Harrier — на MPS в BF16. Для каждого веса измерено 297 серверных задержек после прогрева (99 запросов × три прохода, один клиент). Таймер охватывает обработку HTTP-запроса до готового JSON. Всего 15 147 измерений.
