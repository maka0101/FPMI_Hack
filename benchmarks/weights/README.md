# Доля BM25 в гибридном поиске

[Уточнённая сетка с шагом 0,01 на 99 исходных запросах](weights-fine.md)

Проверены 11 весов для каждого из трёх лучших эмбеддеров по nDCG@10 на официальных 99 запросах предыдущего прогона. Harrier 270M получил 0,9815, Granite 97M — 0,9723, E5-small — 0,9696. Для каждой модели измерены те же 99 исходных запросов и 99 парных перефразировок с исходной разметкой. В каждой группе 42 запроса с одним релевантным письмом.

Вес применяется к позиции письма в списке соответствующей ветки. Для письма на позициях `r_bm25` и `r_dense` сумма равна `w/(60+r_bm25) + (1−w)/(60+r_dense)`. Отсутствие письма в списке даёт нулевой вклад. В обеих ветках фильтры по ящику и дате применяются перед отбором 50 кандидатов. В эксперименте использовался двухветочный режим `hybrid` без выжимки и реранкера. В крайних точках выполнялась одна поисковая ветка. Для каждой модели и каждого запроса проверено точное совпадение упорядоченных top-10 с текущим гибридом в точке 0,5 и с BM25 в точке 1.

Recall@10 и nDCG@10 усреднены по всем 99 запросам группы. MRR@10 в таблицах — средняя обратная позиция целевого письма по 42 запросам с одной целью, как в метрике проекта. Если письмо отсутствует в десятке, вклад равен нулю. JSON дополнительно содержит MRR по первому релевантному письму на всех 99 запросах.

Модели запускались последовательно на Apple M4 Pro. Один клиент отправлял реальные запросы в локальный `/api/search`. После прогрева сделано три прохода в перемешанном порядке, всего 19 602 измеренных HTTP-вызова. Каждый p99 рассчитан методом ближайшего ранга по 297 значениям серверного времени для одного веса и группы. Замер начинается с разбора HTTP-запроса и заканчивается после сериализации JSON. Загрузка сервиса, индексация, сеть и передача ответа клиенту находятся за границами замера.

## Выбор по 99 исходным запросам на сетке с шагом 0,1

Вес для каждой модели выбран по максимуму nDCG@10 на официальных публичных запросах. Перефразировки используются для отдельной проверки устойчивости.

| Модель | BM25 / эмбеддер | Recall@10 | nDCG@10 | MRR@10 | Серверный p99, мс |
|---|---:|---:|---:|---:|---:|
| Harrier 270M | 70 / 30 | 0,9345 | 0,9878 | 1,0000 | 22,87 |
| E5-small | 90 / 10 | 0,9366 | 0,9857 | 1,0000 | 7,90 |
| Granite 97M | 90 / 10 | 0,9330 | 0,9854 | 1,0000 | 43,46 |

На этой сетке Harrier 70/30 лидирует по nDCG@10, E5-small 90/10 — по Recall@10. У самого Harrier переход с 70/30 на 90/10 поднимает Recall@10 с 0,9345 до 0,9354 и снижает nDCG@10 с 0,9878 до 0,9864.

## Воспроизведение

Запустите по одной модели в её окружении с локальными весами и индексом.

```sh
.venv/bin/python -m benchmarks.weight_grid --embedder e5 --output benchmarks/weights/weights-e5.json
.cache/ml-venv/bin/python -m benchmarks.weight_grid --embedder granite97 --output benchmarks/weights/weights-granite97.json
.cache/ml-venv/bin/python -m benchmarks.weight_grid --embedder harrier270 --output benchmarks/weights/weights-harrier270.json
```
