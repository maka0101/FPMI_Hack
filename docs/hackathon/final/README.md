# Умный поиск в Почте · защита

[Презентация для показа, PDF](mail-search.pdf) · [Речь, поминутный план, демо и вопросы жюри](speech.md) · [Редактируемые слайды Slidev](slides.md)

Семь слайдов, один спикер, ориентир на три минуты. Для показа без интернета откройте PDF. Для живого демо подготовьте веб-прототип по сценарию в речи. Снимки интерфейса на слайдах 2 и 3 сохранены в репозитории.

## Показ и экспорт из исходников

Из этого каталога с Node.js 22.12+ и pnpm 11 выполните:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте адрес, который напечатает Slidev. Клавиша P включает режим докладчика с заметками. Для подготовки статической версии выполните `pnpm build`. Для PDF один раз установите браузер командой `pnpm exec playwright install chromium`, затем запустите `pnpm run export`. Выходной файл — `mail-search.pdf`. PDF включает оба снимка и открывается без запущенного сервиса.
