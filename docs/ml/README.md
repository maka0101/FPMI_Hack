# Работа ML-команды с поиском

Цикл эксперимента состоит из подготовки индекса, проверки кандидатов и сравнения на одинаковом наборе запросов. Из корня репозитория запустите:

```sh
uv sync --locked --python 3.11
source .venv/bin/activate
python -m mail_search prepare --profiles encoder-a,encoder-b
python -m mail_search compare --profiles encoder-a,encoder-b --limit 10 --out runs/dev
```

В первом шаге подготовки появятся индексы для двух встроенных CPU-профилей. Повторный запуск использует те же артефакты. Сравнение создаёт отчёт с BM25, encoder и hybrid для обоих профилей. Встроенные профили используют хешированные лексические признаки и подходят для проверки интеграции. Для эксперимента с обученным энкодером добавьте YAML-профиль Sentence Transformers по спецификации. [Профили и индексы](profiles-and-indexes.md) · [Эксперименты](experiments.md)

## Проверка браузером

В первом терминале поднимите ML, во втором запустите backend с тем же профилем. Оба процесса используют корпус из репозитория.

```sh
python -m mail_search.ml --data mipt_mail_search_participants --profile encoder-a --host 127.0.0.1 --port 8001
```

```sh
SEARCH_MODE=hybrid MODEL_PROFILE=encoder-a python -m mail_search serve
```

В локальном UI выберите ящик `box-2d28af4e4602` и дату `2025-10-20`. Запрос «Покажи уведомления о получении новых заказов, полученные вчера.» должен показать день `2025-10-19`. Выберите результат и откройте письмо. Чтобы проверить вторую модель, перезапустите оба процесса с профилем `encoder-b`. Для возврата повторите запуск с `encoder-a`.

- Добавить модель, понять формат профиля и совместимость индекса. [Профили и индексы](profiles-and-indexes.md)
- Проверить запрос к ML, готовность и правила фильтрации. [Контракт Backend ↔ ML](../contracts/ml-search-v1.md)
- Сравнить результаты, повторить прогон и измерить задержку. [Эксперименты](experiments.md)
- Сравнить BM25, USER2-base и гибриды на запросах к периоду. [Эксперимент с ранжированием писем](../ranking-evaluation.md)
- Поднять Compose, подключить VM через SSH, переключить модель и проверить откат. [Инфраструктура](../infrastructure.md)
